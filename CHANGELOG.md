# Изменения

Версии по [SemVer](https://semver.org/lang/ru/). Пока кит в версии 0.x, классы могут меняться в минорных версиях — о таких изменениях здесь будет отдельный пункт «Несовместимо».

## Не выпущено

### Грид
- Открытие записи кликом по строке, как в списках Битрикс24: `tr[data-href]` (Ctrl/⌘ и средняя кнопка — новая вкладка) или для всех строк `data-row-open` / `rowOpen: true` / `onRowOpen(id, row, event)`. Событие `b24:row-open { id, row, href, newTab }`, `preventDefault` отменяет переход. Ссылки, кнопки, чекбокс, ☰, редактируемые ячейки, `[data-no-open]` и выделение текста строку не открывают; курсор-указатель на строках.

### Элементы управления
- Оценка звёздами: `[data-b24-rating]` / `createRating` / `<Rating>`. Скрытое поле для формы, наведение, повторный клик — сброс, клавиатура (стрелки, Home/End, цифры, Delete), режим только для показа, `disabled`, размеры `sm`/`lg`, событие `b24:rating-change`, `getRating(el)`; сброс формы возвращает начальную оценку.

## 0.5.1 — 2026-10-19

### Шапка раздела
- Меню раздела из вкладок на одной странице: пункт `{ tab: 'id' }` в `createPageHeader` — кнопка `[data-b24-tab]`, панели `[data-b24-tab-panel]` переключает `initTabs`, `setMenu(id)` переключает и их. В React пункт без `href` с `onClick` — кнопка.
- `button.b24-topnav__item` без оформления браузера (рамка, серый фон); активный пункт подсвечивается и по `aria-selected="true"`.

### Блок разработчика
- `links.license` — «Лицензионное соглашение» рядом с политикой конфиденциальности.
- `links.contacts` необязателен: связь с разработчиком и так есть через поддержку. Обязательными остались название, поддержка и политика конфиденциальности (`links.privacy`).

## 0.5.0 — 2026-10-19

### Шапка раздела — правило кита
- `createPageHeader(host, options)` и `<PageHeader>`, CSS `.b24-page-header`: шапка как в разделах портала (CRM, Задачи). Меню раздела → «Заголовок · Создать · селекторы · фильтр … tools» → «вид · счётчики … extra», служебный угол `aside` с блоком разработчика. Порядок задаёт CSS (`order`), разметкой его не переставить. API: `setTitle`, `setMenu`, `setView`, `setCounter`, `slots`, `filter`, `vendor`; на светлом фоне — `light` / `--light`.
- Проверка компоновки `checkLayout()` / `warnLayout()`: основная кнопка или фильтр справа (`.b24-toolbar__right`, `__tools`, `__extra`, `__aside`, `.b24-page-bar`), «Создать» после фильтра, текст в `__tools` — замечание в консоль. Запускается в конце `init()` и в `<PageHeader>`; выключить — `<html data-b24-layout-check="off">`.
- `AGENTS.md` — правила интерфейса для ИИ-агентов и разработчиков, копируется в `dist/AGENTS.md`. В CLAUDE.md приложения — одна строка со ссылкой на него.
- `<Toolbar>` помечен устаревшим для шапки раздела; `.b24-toolbar` работает как раньше. Демо и README переведены на шапку раздела.

## 0.3.0 — 2026-10-14

### Экраны приложения
- Пустые состояния с тоном (`--neutral`, `--access`, `--error`, `--success`), компактные и на подложке Air.
- Страница настроек `.b24-settings[data-b24-settings]`: разделы с подсветкой, строки `.b24-setting`, панель сохранения `.b24-savebar`, событие `b24:settings-save`.
- Дашборд: сетка `.b24-dashboard`, плитки `.b24-kpi`, рейтинг `.b24-meters`.
- Графики `createChart` / `[data-b24-chart]`: линия, область, столбцы, кольцо; спарклайн. Токены палитры `--b24-chart-1…6`.
- Степпер `.b24-stepper` и мастер `.b24-wizard[data-b24-wizard]` с асинхронной проверкой шага.
- React: `Chart`, `Sparkline`, `Kpi`, `Stepper`, `SettingRow`, `SaveBar`, `EmptyScreen`.

### Редакторы полей
- `createCombobox`: выпадающий список без `<select>` с группами, поиском по коду, счётчиком «N из M» и свободным вводом; у `select[data-b24-combobox]` — `data-creatable`, `data-counter`.
- `createRepeater` и `[data-b24-repeater]` для серверных форм; `createKeyValue` — пары «ключ → значение».
- `createFieldMapper`: сопоставление полей с шаблонами, правилами обновления, словарём значений, суммой прописью, склонением ФИО и ошибками сервера по пути.
- React: `KeyValueEditor`, `FieldMapper`; у `Combobox` — `creatable`, `counter`, `groupBy`.
- `createCombobox`: поиск на сервере (`load`), поиск по ID (`loadById`), выбранное чипом (`display: 'chip'`).
- Журнал `createLogViewer`, блок кода `codeHtml`, подсветка `jsonHtml` и `traceHtml`; React — `LogViewer`, `CodeBlock`, `JsonView`.
- Таблица: тон строки (`tr.is-danger/warning/success/info`), раскрывающиеся строки, «было → станет» (`diffHtml`, `DiffValue`), чипы-ссылки (`chipHtml`, `Chip`), выбор в ячейке `.b24-cell-choice`. У `DataTable` — `rowTone`, `renderExpanded`, `expanded`, `onExpandedChange`.
- Формат преобразований `createFieldMapper` совпадает с хранением в приложении: `map` — объект, `on_missing`, `amount_words { currency, fraction }`, `inflect { case: 'genitive' … }`.

### Элементы управления
- Аккордеон для приложения, карточки-радио, группа чекбоксов, сегментированный переключатель, ползунок и диапазон, выбор цвета, поле секрета, дерево, всплывающая подсказка с кнопками, обучение по шагам.
- `applyServerErrors` / `clearServerErrors`, `crmEntityUrl`, `plural` / `formatCount`; бейдж со спиннером, пульсирующая точка.
- Тосты: одинаковые склеиваются, видимых не больше четырёх (`TOAST_LIMIT`).

### Грид
- Подвал: «Отмечено: N / M», «Всего» или «Показать количество», действия по отметке и «по фильтру» (`when: 'selected' | 'none' | 'always'`, `disabled`, `hint`), номера страниц, «На странице», «Показать ещё» с догрузкой в тот же `tbody`; события `b24:page-change`, `b24:page-size-change`, `b24:load-more`. Размер страницы запоминается. Во фрейме портала панель всплывает у места отметки в длинной таблице.
- `getGrid(table)` — грид из автоинициализации; `replaceRows` / `appendRows` / `getPagination`. Восстановленный размер страницы приходит событием `b24:page-size-change { restored: true }`. `window.B24UI` доступен и при подключении `global` модулем.

### Планировщик
- `createScheduler` / `<Scheduler>`: сотрудники × время (день, неделя, месяц), график работы и отсутствия, встречи с перетаскиванием, растягиванием и созданием, откат при отказе сервера, конфликты и загрузка, виртуализация строк, клавиатура. `bx24SchedulerLoader` — занятость из календаря портала.

### Язык подписей
- Встроенные подписи на русском и английском: `setLocale`, `getLocale`, `addMessages`, `t`, `intlLocale`; язык по умолчанию — из `<html lang>`. Свои языки добавляются словарём, ключ — русская фраза.

### Разработка
- Тесты поведения компонентов приложения: грид (сортировка, выбор, меню строки, редактирование ячейки, скрытие столбцов), фильтр, даты и время, несколько значений, канбан, модалки и слайдеры, тосты во фрейме.

### Документация
- Фильтр показан как компонент тулбара (`.b24-toolbar__search`), в README — разметка; ширину фильтра задаёт контейнер.

### Исправлено
- Правая часть тулбара переносится на узком экране, а не уходит за край.
- Скрытая подсказка `[data-b24-tooltip]` у правого края больше не даёт горизонтальную прокрутку: она создаётся только при наведении.
- Подсветка раздела (якорное меню, оглавление, настройки) пересчитывается, когда раздел появляется без прокрутки, и не перескакивает на последний раздел после клика внизу страницы.

## 0.2.0 — 2026-10-02

Компоненты для сайтов и лендингов приложений. Подробности и таблицы классов — в README, раздел «Сайт и лендинги приложений».

### Сайт приложения
- Текст и документы: `.b24-prose`, `.b24-document` (строка `h1 + p` — «Редакция от…»), `.b24-document-card`.

### Корпоративный сайт
- Раскладка: `.b24-site`, `.b24-container`, секции `.b24-section` на подложке Air и светлом фоне.
- Липкая шапка `.b24-site-header[data-b24-site-header]`: меню на `details`, мегаменю, бургер на узком экране.

- Маркетинговые блоки: призыв `.b24-cta`, тарифы с переключателем месяц/год без JS, сравнение тарифов, FAQ, цифры, отзывы, логотипы, команда, контакты, видео с постером.

### Контент
- Статья с липким оглавлением `.b24-toc[data-b24-toc]`, врезки `.b24-callout`, иллюстрации `.b24-figure`, таблицы с прокруткой.
- Блог: карточки статей `.b24-post-card`, лента новостей `.b24-news`, пагинация `.b24-site-pagination`, ссылка со стрелкой, бейджи «Скоро / Новое / Бесплатно / Бета / Хит».

- Уведомление о cookie `[data-b24-cookie]`, переключатели темы `[data-b24-theme-switch]` и языка `.b24-lang-switch`.
- Для страниц приложений: `.b24-page-bar` (заголовок + вкладки), `.b24-app-intro`, `.b24-props--columns`, список документов `.b24-doc-index`.
- Стили печати для документов и статей.
