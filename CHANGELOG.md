# Изменения

Версии по [SemVer](https://semver.org/lang/ru/). Пока кит в версии 0.x, классы могут меняться в минорных версиях — о таких изменениях здесь будет отдельный пункт «Несовместимо».

## Не выпущено

### Мессенджер сквозь раздел
- `createMessengerBar` / `<MessengerBar>` — правая панель, как у портала: «Все чаты», аватары диалогов со счётчиками, статусом и подсказкой «имя · канал», кнопки внизу; на ≤768px скрыта; контент отступает (`html.b24-has-im-bar`).
- `openChatDock` / `<ChatDock>` — плавающее окно чата у правого края: лента и поле ответа, «Открыть полностью», «Свернуть» (полоска со счётчиком), «Закрыть»; несколько окон в ряд; на телефоне — нижний лист на 70% высоты.
- `notifySound` (WebAudio, без файла), `desktopNotify`, `requestNotifyPermission`, `claimNotify` — звук и системные уведомления с дедупликацией между вкладками.

## 0.11.1 — 2026-11-16

### Чаты
- В пустом поле ответа больше нет полосы прокрутки: `autoResize` учитывает рамку при `box-sizing: border-box`, прокрутка появляется только у `max-height` (касается и композера таймлайна).
- Ленту и поле можно создавать в своих обёртках внутри `.b24-chat__main` — обёртка ленты растягивается, поле прижато к низу.

## 0.10.0 — 2026-11-16

### Канбан
- Шапка, сумма, «+» и форма в колонке больше не сжимаются, когда карточек много: прокручивается только список (`.b24-kanban__items { flex: 1 1 0; min-height: 0 }`, карточки `flex-shrink: 0`). Раньше в длинной колонке шапки становились тонкими, а карточки налезали друг на друга.
- `enableKanbanDnd` можно вызывать повторно: обработчики не дублируются, новые опции заменяют прежние, возвращается та же функция отключения. Колонки с `data-color` красит сам — при ручном рендере без `data-b24-kanban` текст шапки теперь контрастный.
- Быстрое добавление, как на портале: круглый «+» (`.b24-kanban__add--round`), `enableKanbanQuickAdd(board, { fields, onSave })` / `openKanbanQuickAdd(column, …)`, в React — `onQuickAdd(columnId, values)` и `quickAddFields`. Форма `.b24-kanban__quick` помещается в колонку шириной 150–250px.
- `stagePicker(el, { stages, value, onChange })` / `<StagePicker>` — выбор стадии в карточке: одна строка с прокруткой без полосы, края затухают, цвет стадии фоном, выбранная — сплошным с контрастным текстом, текущая прокручивается в центр. Стрелки, Home/End.

### Планировщик
- Статус сотрудника: `online` / `status: 'online' | 'away'` — точка у аватара, `lastSeen` — подсказка «Был(а) в сети N мин назад». Точка рисуется вместе со строкой и не пропадает при прокрутке.
- `setDays(n)`, `setRange(start, n)` и `days` у обёртки — период вида «N дней» меняется без пересоздания (масштаб, свёрнутые отделы и вертикальная прокрутка сохраняются). В React работают пропсы `days` и `date`.
- `initialScroll: 'center'`, `scrollToDate(date, 'center' | 'start')`, `scrollToTime(date, align)`.
- Свои виды графика: любой `kind` с `label`, `color`, `className` — подпись, штриховка цветом, пункт легенды. Встреча поверх своего вида не конфликт (`absent: true` — конфликт).
- У события `className` и `variant: 'dashed' | 'hatched'`.

### Раздел и подразделы
- Меню раздела (как «Сделки · Счета · Компании · Контакты» в CRM): пункты, что не помещаются, уходят в «Ещё ▾» — со своими счётчиками, сумма счётчиков на «Ещё», открытый подраздел всегда на виду. Само в `createPageHeader`, `<PageHeader>`, `<TopNav>` и разметке `.b24-page-header__menu` (через `init()`); `initTopnavMore(nav)`, `.b24-topnav[data-b24-more]`, выключить — `data-b24-more="off"`. Раньше меню прокручивалось по горизонтали.
- Паттерн «раздел → подразделы» описан в README и AGENTS.md (правило 8): в сайдбаре только раздел, подсвечен на подстраницах (`aria-current="page"` или `"true"`), подразделы — меню раздела.
- `.b24-tabs--glass` без `--pills` выглядел сломанным (полоса на всю ширину, пункты без отступов и скругления) — теперь сам по себе пилюли на тёмной подложке.

### Аватар
- Точка статуса `.b24-avatar__status` больше не обрезается: у `.b24-avatar` убран `overflow: hidden`, картинку скругляет свой `border-radius`.
- `avatarHtml(name, src, size, { status: 'online' | 'away', title })` — точка без ручной вставки `<span>`; `.b24-avatar__status.is-away` — жёлтая. В React — `<Avatar status="away" title="…" />`.

### Фильтр
- `count` у пресетов и вариантов полей — число рядом с названием; `filter.setCounts(…)` обновляет числа.
- Строка фильтра по умолчанию не шире 800px (`--b24-filter-max-width`), как в Битрикс24 — на широком экране она больше не растягивается на 1900px. Опция `maxWidth` (число, строка или `'none'`), модификатор `.b24-filter--full`. **Несовместимо:** кому нужна вся ширина — `maxWidth: 'none'`.

### Экран блокировки
- Окна и подтверждения, открытые поверх экрана блокировки (например, `confirm` из `onOtherUser`), теперь над ним, а не под; цифры и Esc в окне не уходят в экран. Новый токен `--b24-z-lock` (90000).

### Раскладка
- `.b24-rows` — сетка в одну колонку `minmax(0, 1fr)`. `.b24-props` и поля карточки (`.b24-editor-section__fields`) тоже не растягиваются по самому широкому ребёнку. В `.b24-sidepanel__body` дети не шире панели.

- React: `KeyValueEditor`, `FieldMapper`; у `Combobox` — `creatable`, `counter`, `groupBy`.
- `createCombobox`: поиск на сервере (`load`), поиск по ID (`loadById`), выбранное чипом (`display: 'chip'`).
- Журнал `createLogViewer`, блок кода `codeHtml`, подсветка `jsonHtml` и `traceHtml`; React — `LogViewer`, `CodeBlock`, `JsonView`.
- Таблица: тон строки (`tr.is-danger/warning/success/info`), раскрывающиеся строки, «было → станет» (`diffHtml`, `DiffValue`), чипы-ссылки (`chipHtml`, `Chip`), выбор в ячейке `.b24-cell-choice`. У `DataTable` — `rowTone`, `renderExpanded`, `expanded`, `onExpandedChange`.
- Формат преобразований `createFieldMapper` совпадает с хранением в приложении: `map` — объект, `on_missing`, `amount_words { currency, fraction }`, `inflect { case: 'genitive' … }`.

### Элементы управления
- Аккордеон для приложения, карточки-радио, группа чекбоксов, сегментированный переключатель, ползунок и диапазон, выбор цвета, поле секрета, дерево, всплывающая подсказка с кнопками, обучение по шагам.
- `applyServerErrors` / `clearServerErrors`, `crmEntityUrl`, `plural` / `formatCount`; бейдж со спиннером, пульсирующая точка.
- Тосты: одинаковые склеиваются, видимых не больше четырёх (`TOAST_LIMIT`).

### Грид
- Подвал: «Отмечено: N / M», «Всего» или «Показать количество», действия по отметке и «по фильтру» (`when: 'selected' | 'none' | 'always'`, `disabled`, `hint`), номера страниц, «На странице», «Показать ещё» с догрузкой в тот же `tbody`; события `b24:page-change`, `b24:page-size-change`, `b24:load-more`. Размер страницы запоминается. Во фрейме портала панель всплывает у места отметки в длинной таблице.
- `getGrid(table)` — грид из автоинициализации; `replaceRows` / `appendRows` / `getPagination`. Восстановленный размер страницы приходит событием `b24:page-size-change { restored: true }`. `window.B24UI` доступен и при подключении `global` модулем.

### Планировщик
- `createScheduler` / `<Scheduler>`: сотрудники × время (день, неделя, месяц), график работы и отсутствия, встречи с перетаскиванием, растягиванием и созданием, откат при отказе сервера, конфликты и загрузка, виртуализация строк, клавиатура. `bx24SchedulerLoader` — занятость из календаря портала.

### Язык подписей
- Встроенные подписи на русском и английском: `setLocale`, `getLocale`, `addMessages`, `t`, `intlLocale`; язык по умолчанию — из `<html lang>`. Свои языки добавляются словарём, ключ — русская фраза.

### Разработка
- Тесты поведения компонентов приложения: грид (сортировка, выбор, меню строки, редактирование ячейки, скрытие столбцов), фильтр, даты и время, несколько значений, канбан, модалки и слайдеры, тосты во фрейме.

### Документация
- Фильтр показан как компонент тулбара (`.b24-toolbar__search`), в README — разметка; ширину фильтра задаёт контейнер.

### Исправлено
- Правая часть тулбара переносится на узком экране, а не уходит за край.
