# Изменения

Версии по [SemVer](https://semver.org/lang/ru/). Пока кит в версии 0.x, классы могут меняться в минорных версиях — о таких изменениях здесь будет отдельный пункт «Несовместимо».

## Не выпущено

### Экраны приложения
- Пустые состояния с тоном (`--neutral`, `--access`, `--error`, `--success`), компактные и на подложке Air.
- Страница настроек `.b24-settings[data-b24-settings]`: разделы с подсветкой, строки `.b24-setting`, панель сохранения `.b24-savebar`, событие `b24:settings-save`.
- Дашборд: сетка `.b24-dashboard`, плитки `.b24-kpi`, рейтинг `.b24-meters`.
- Графики `createChart` / `[data-b24-chart]`: линия, область, столбцы, кольцо; спарклайн. Токены палитры `--b24-chart-1…6`.
- Степпер `.b24-stepper` и мастер `.b24-wizard[data-b24-wizard]` с асинхронной проверкой шага.
- React: `Chart`, `Sparkline`, `Kpi`, `Stepper`, `SettingRow`, `SaveBar`, `EmptyScreen`.

### Редакторы полей
- `createCombobox`: выпадающий список без `<select>` с группами, поиском по коду, счётчиком «N из M» и свободным вводом; у `select[data-b24-combobox]` — `data-creatable`, `data-counter`.
- `createRepeater` и `[data-b24-repeater]` для серверных форм; `createKeyValue` — пары «ключ → значение».
- `createFieldMapper`: сопоставление полей с шаблонами, правилами обновления, словарём значений, суммой прописью, склонением ФИО и ошибками сервера по пути.
- React: `KeyValueEditor`, `FieldMapper`; у `Combobox` — `creatable`, `counter`, `groupBy`.
- `createCombobox`: поиск на сервере (`load`), поиск по ID (`loadById`), выбранное чипом (`display: 'chip'`).
- Журнал `createLogViewer`, блок кода `codeHtml`, подсветка `jsonHtml` и `traceHtml`; React — `LogViewer`, `CodeBlock`, `JsonView`.
- Таблица: тон строки (`tr.is-danger/warning/success/info`), раскрывающиеся строки, «было → станет» (`diffHtml`, `DiffValue`), чипы-ссылки (`chipHtml`, `Chip`), выбор в ячейке `.b24-cell-choice`. У `DataTable` — `rowTone`, `renderExpanded`, `expanded`, `onExpandedChange`.
- Формат преобразований `createFieldMapper` совпадает с хранением в приложении: `map` — объект, `on_missing`, `amount_words { currency, fraction }`, `inflect { case: 'genitive' … }`.

### Элементы управления
- Аккордеон для приложения, карточки-радио, группа чекбоксов, сегментированный переключатель, ползунок и диапазон, выбор цвета, поле секрета, дерево, всплывающая подсказка с кнопками, обучение по шагам.
- `applyServerErrors` / `clearServerErrors`, `crmEntityUrl`, `plural` / `formatCount`; бейдж со спиннером, пульсирующая точка.
- Тосты: одинаковые склеиваются, видимых не больше четырёх (`TOAST_LIMIT`).

### Исправлено
- Правая часть тулбара переносится на узком экране, а не уходит за край.
- Подсветка раздела (якорное меню, оглавление, настройки) пересчитывается, когда раздел появляется без прокрутки, и не перескакивает на последний раздел после клика внизу страницы.

## 0.2.0 — 2026-10-02

Компоненты для сайтов и лендингов приложений. Подробности и таблицы классов — в README, раздел «Сайт и лендинги приложений».

### Сайт приложения
- Текст и документы: `.b24-prose`, `.b24-document` (строка `h1 + p` — «Редакция от…»), `.b24-document-card`.
- Карточки приложений `.b24-product-card`, галерея скриншотов с лайтбоксом `[data-b24-gallery]`, верхнее меню `.b24-topnav`, подвал `.b24-site-footer`, герой, преимущества, шаги, хлебные крошки, история версий.

### Корпоративный сайт
- Раскладка: `.b24-site`, `.b24-container`, секции `.b24-section` на подложке Air и светлом фоне.
- Липкая шапка `.b24-site-header[data-b24-site-header]`: меню на `details`, мегаменю, бургер на узком экране.
- Мегаменю с категориями `.b24-megamenu--panes`: слева категории, справа панель выбранной. Работает без JS, на узком экране — аккордеон. Метки «for Bitrix24» под пунктом: `.b24-megamenu__tags`.
- Якорное меню `.b24-anchor-nav[data-b24-anchor-nav]` с подсветкой секции.
- Маркетинговые блоки: призыв `.b24-cta`, тарифы с переключателем месяц/год без JS, сравнение тарифов, FAQ, цифры, отзывы, логотипы, команда, контакты, видео с постером.

### Контент
- Статья с липким оглавлением `.b24-toc[data-b24-toc]`, врезки `.b24-callout`, иллюстрации `.b24-figure`, таблицы с прокруткой.
- Блог: карточки статей `.b24-post-card`, лента новостей `.b24-news`, пагинация `.b24-site-pagination`, ссылка со стрелкой, бейджи «Скоро / Новое / Бесплатно / Бета / Хит».
- Формы без JS: `.b24-site-form`, согласие `.b24-consent`, ошибки на `:user-invalid`, состояния `.is-sent` и `.b24-form-status`; подписка `.b24-subscribe`.
- Уведомление о cookie `[data-b24-cookie]`, переключатели темы `[data-b24-theme-switch]` и языка `.b24-lang-switch`.
- Для страниц приложений: `.b24-page-bar` (заголовок + вкладки), `.b24-app-intro`, `.b24-props--columns`, список документов `.b24-doc-index`.
- Стили печати для документов и статей.

### JS
- `initSiteHeader`, `initAnchorNav`, `initToc`, `initCookieNotice`, `initThemeSwitch`, `applyStoredTheme`, `initVideo`, `initGallery`, `openLightbox`, `initTopnav`. Всё включается само по data-атрибутам.

### Исправлено
- Грид: без пустой колонки чекбоксов, когда чекбоксов в разметке нет.
- Повторный клик по пункту меню больше не выделяет текст страницы.

### Разработка
- Тесты поведения на Playwright: `npm test`.
