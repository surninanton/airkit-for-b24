# Бэклог

Развитие кита после 0.2.0. Порядок — по пользе для приложений; сделанное переносится в [CHANGELOG.md](CHANGELOG.md).

## 1. Типовые экраны приложения ✓

Кирпичики есть (грид, фильтр, канбан, формы, слайдер), но каждое приложение заново собирает из них одни и те же экраны.

- [x] **Пустые состояния**: «пока нет данных», «нет прав», «ничего не найдено». Иллюстрация, текст, кнопка действия.
- [x] **Страница настроек**: разделы слева, форма справа, сохранение.
- [x] **Дашборд**: карточки с цифрами и простые графики в стиле Air (линия, столбцы, кольцо). Графиков в ките нет совсем.
- [x] **Мастер первой настройки**: шаги «подключение → права → готово», степпер с состояниями шагов.

Пустые состояния, настройки и дашборд сразу пригодятся в «Обходчиках и журнале БП».

## 2. Недостающие элементы управления ✓

- [x] Сегментированный переключатель.
- [x] Ползунок и диапазон.
- [x] Выбор цвета.
- [x] Дерево: разделы, папки, структура компании.
- [x] Всплывающая подсказка с текстом и кнопками (popover), подсказка-обучение по шагам.
- [x] Аккордеон для приложений (сейчас есть только `.b24-faq` для сайта).

## 3. Тесты компонентов приложения ✓

Сейчас грид, фильтр, выбор дат и канбан проверяются только на отсутствие ошибок при загрузке демо.

- [x] Грид: сортировка, ширина и порядок столбцов, закрепление, редактирование в ячейке, выбор строк и групповые действия.
- [x] Фильтр: пресеты, поля, сборка запроса к REST.
- [x] Выбор даты и времени, поле из нескольких значений, выбор сотрудников.
- [x] Канбан: перетаскивание между стадиями.
- [x] Слайдер, модалки и тосты, в том числе во фрейме портала.

## 4. Языки встроенных подписей ✓

Подписи внутри компонентов («Открыть меню», «Сегодня», «Ничего не найдено» и т. д.) сейчас только на русском.

- [x] Вынести подписи в словарь, добавить английский, переключать языком страницы или настройкой.

## 5. Подключение по версии

Оба потребителя берут кит из соседней папки (`../sdk-ui-bitrix24/dist`).

- [ ] Публиковать в GitHub Packages (репозиторий остаётся приватным), чтобы подключать `airkit-for-b24@0.2.0` и обновляться осознанно.
- [ ] Перевести «Обходчики и журнал БП» и appb24.ru на пакет — по согласованию с их сессиями.

## 6. Компоненты для переноса autosinc_b24_and_metabase ✓

Запрос сессии приложения синхронизации Metabase → Битрикс24 (Laravel + Vue 3). Полный разбор — `docs/ui-kit-gaps.md` в репозитории приложения (ветка `docs/backlog`, PR #16).

**Решение по Vue (2026-10-02): вариант (а).** Кит остаётся на CSS + vanilla JS (+ React). Vanilla API обязан покрывать всё поведение сложных виджетов, а Vue-обёртки над ним тонкие и монтируют виджет в `onMounted`. Обёртки делаются на стороне приложения, кит их не поставляет.

Порядок: пункты 1–3 (без них форма интеграции не переносится), затем 4–5, затем остальное.

- [x] **1. Редактор сопоставления полей.** Строка «колонка Metabase → поле Б24 → правило обновления (always / if_empty / if_changed / never)», переключатель «колонка ↔ шаблон» (`{{Имя}} {{Фамилия}}`), тумблер словаря с индикацией «настроен», удаление, добавление, пустое состояние. Под строкой — панель словаря: пары «значение → значение Б24» (справа select с группами, например стадии по воронкам, или свободный ввод), блок on_missing (pass / default / skip / fail) с зависимым полем default. Выбор типа преобразования: value_map / amount_words (сумма прописью) / inflect (склонение ФИО). Второй экземпляр для дочерней сущности со своим справочником полей. Минимум — собрать из пунктов 2 и 3.
- [x] **2. Повторяющиеся строки (Repeater) и редактор «ключ → значение»:** добавление и удаление, пустое состояние, стрелка между полями.
- [x] **3. Combobox:** группы («Системные / Пользовательские» по префиксу `UF_`), поиск по коду и названию сразу, липкий футер «N из M», свободный ввод (creatable) — сохранять «сырое» значение, когда справочник не загрузился.
- [x] **4. Таблица:** раскрывающиеся строки, богатые ячейки (diff «было → станет», плашки предупреждений, чипы-ссылки, подтверждение с выбором прямо в ячейке), тон строки по статусу (ошибка / расхождение / совпадение).
- [x] **5. Аккордеон для приложения:** заголовок-кнопка, шеврон, счётчик, вложенность (совпадает с пунктом раздела 2).
- [x] **6. Карточки-радио (RadioCards):** цветная рамка, галочка в углу, описание.
- [x] **7. Группа чекбоксов:** подписи с `#id`, ссылки «все / очистить», прокрутка.
- [x] **8. DiffValue:** `поле: ~~старое~~ → новое`, «(без изменений)», «пусто».
- [x] **9. Просмотр логов и JSON:** тёмная консоль, фильтр уровней, подсветка JSON и стектрейса, раскрытие контекста, копирование, «загрузить ещё». Минимум — блок кода с тоном строк.
- [x] **10. Combobox с асинхронным поиском и чипом после выбора:** аватар, ссылка, `#id`, крестик; ввод числового ID ищет по ID.
- [x] **11. Поле секрета:** пароль с «глазом», маска сохранённого значения, «введите новый, чтобы заменить».
- [x] **12. `crmEntityUrl(type, id, typeId?)`:** ссылки на карточки CRM, включая смарт-процессы (`/crm/type/{typeId}/details/{id}/`).
- [x] **13. `applyServerErrors(errors)`:** ошибки Laravel 422 по пути (`child.field_mappings.6.metabase_field`) — в ошибки полей.
- [x] **14. Тон строки у `.b24-table`:** `tr.is-warning`, `tr.is-success` для таблицы сравнения в iframe.
- [x] **15. Мелочи:** бейдж со спиннером, пульсирующая точка «идёт», очередь тостов без наложения, русская плюрализация.
